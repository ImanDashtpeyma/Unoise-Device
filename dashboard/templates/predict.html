Model Performance Metrics

Model Summaries

  • ARIMA (AutoRegressive Integrated Moving Average): A traditional statistical model designed to capture trends and seasonality in time series data. Simple but effective for stationary series. Delivered consistent results with moderate error metrics.
  • Random Forest: A machine learning algorithm based on decision trees, robust against overfitting and effective at capturing non-linear relationships.
  • SVM (Support Vector Machine): An algorithm that identifies the optimal hyperplane for data separation. Useful for small datasets with high dimensionality.
  • XGBoost (Extreme Gradient Boosting): An advanced gradient boosting algorithm optimized for speed and performance. Excellent at capturing complex relationships in data, delivering consistent and competitive results.

Metric Descriptions

  • MAE (Mean Absolute Error): Measures the average absolute error between predictions and actual values. Smaller values indicate higher accuracy (lower is better).
  • MedAE (Median Absolute Error): Median of absolute errors, less sensitive to outliers than MAE. Smaller values indicate better performance (lower is better).
  • MSE (Mean Squared Error): Penalizes larger errors more severely, useful for identifying significant deviations. Smaller values indicate better performance (lower is better).
  • RMSE (Root Mean Squared Error): The square root of MSE, interpretable on the same scale as the data. Smaller values indicate better predictions (lower is better).
  • MAPE (Mean Absolute Percentage Error): Measures the average percentage error, useful for assessing relative accuracy. Smaller percentages indicate better performance (lower is better).
